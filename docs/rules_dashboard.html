Pre-commit Validation

RULE-001
Active

Validates code changes before allowing commits to ensure quality standards are met.

Expected Input
git diff --staged
Expected Output
{ "valid": boolean, "errors": string[] }
Thresholds & Limits
Max file size 1 MB
Max line length 120 chars
pre-commit validation quality

Active

Scans staged files for potential secrets, API keys, and sensitive information.

Expected Input
staged file content
Expected Output
{ "secrets_found": number, "locations": string[] }
Thresholds & Limits
Allowed secrets 0
Scan depth full history
